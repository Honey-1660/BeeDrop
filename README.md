## 01 — BeeDrop

### ⚡ Cross-Platform Local File Sharing

BeeDrop is a cross-platform file-sharing application designed to transfer files quickly and privately between **Windows, macOS, and Android** over the same local network or hotspot.

**Tech Stack**

`Tauri` `React` `Vite` `FastAPI` `Python` `SQLite` `UDP` `mDNS` `WebSocket` `PWA`

**Key Features**

* ⚡ High-speed local file transfers
* 📱 Windows ↔ Android
* 🍎 macOS ↔ Windows
* 📱 Android ↔ macOS
* 🔗 QR-based device pairing
* 🔎 Automatic device discovery
* 🔐 Trusted devices
* 📂 Folder transfers
* 📦 Multiple-file transfers
* 🔄 Resumable transfers
* 📊 Transfer history
* 📡 WebSocket transfer progress
* 🌐 LAN / Wi-Fi / hotspot support
* 🖥️ Windows application
* 🍎 macOS application
* 📱 Android PWA
