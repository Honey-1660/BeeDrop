macOS (Intel) Installation Guide

  1. 1
    Download: Get BeeDrop-macOS.dmg.
  2. 2
    Mount DMG: Double-click the DMG file to open the installer window.
  3. 3
    Install: Drag BeeDrop.app into the Applications folder.
  4. 4
    Launch & Approve: Open from Applications. If security prompt appears, approve via System Settings → Privacy & Security.
  5. 5
    Start Sharing: BeeDrop is ready to discover nearby devices and transfer files!

Windows Installation Guide

  1. 1
    Download Installer: Get BeeDrop-Setup.exe for Windows (10 / 11).
  2. 2
    Run Setup: Double-click BeeDrop-Setup.exe to launch the installer wizard.
  3. 3
    SmartScreen Approval: If Windows Defender SmartScreen appears, click More info → Run anyway.
  4. 4
    Complete Setup: Follow the setup wizard prompts and launch BeeDrop from Start Menu.
  5. 5
    Start Sharing: Allow Firewall access when prompted. BeeDrop is ready to discover nearby devices!

macOS (Apple Silicon M1–M5) Guide & Rosetta 2 Quick FAQ

Installation Guide (M1–M5 Macs)

  1. 1
    Download & Install: Download BeeDrop-macOS.dmg, open it, and drag BeeDrop.app to Applications.
  2. 2
    First Launch Prompt: Open BeeDrop. When prompted "To open BeeDrop, you need to install Rosetta.", click Install.
  3. 3
    Rosetta 2 Setup: Wait ~1 minute while official Apple Rosetta 2 completes installation automatically (1-time only).
  4. 4
    Launch & Share: Open BeeDrop again from Applications. It starts normally and is ready for offline transfers.

Rosetta 2 Quick FAQ

What is Rosetta 2?

Apple's translation layer enabling high performance execution on Apple Silicon Macs.

Is Rosetta 2 safe?

Yes Apple signed & verified.

Which Macs need it?

Apple Silicon Macs (M1–M5). Intel Macs do not require it.

BeeDrop vs Cloud Sharing

Understand the differences between local network file sharing and traditional cloud uploads.

Feature BeeDrop (Local Sharing) Cloud Upload/Download
Workflow Direct device-to-device transfer Upload to server, then download
Network Requirement Same local network (Wi-Fi/LAN) Active internet connection
Storage Requirement Uses only your local device storage Requires available cloud server space
Typical Use Case Transferring heavy files quickly to a nearby device Storing files for backup or remote sharing
Privacy Considerations Files stay on your local network Files reside temporarily on third-party servers

Security & Privacy

Understand how your data is handled during local network transfers.

Local Network Data Handling

BeeDrop is built on the concept of local network file sharing. When you transfer files, they are sent directly over your local Wi-Fi or LAN.

Because this is a private file transfer solution, files do not need cloud storage and are never uploaded to our servers. Connections require direct device pairing, ensuring you explicitly authorize who you are connecting with on your local network. You should always ensure you trust the local network (such as your home Wi-Fi) when sharing sensitive files.

For more details on our data practices, please review our full Privacy Policy and Terms of Service.

Quick Troubleshooting

Common solutions for connection and transfer issues.

Device not found
Ensure both devices are on the exact same Wi-Fi network or mobile hotspot. If using a corporate or public network, AP isolation might be blocking device discovery.
QR code not working
Check that your phone's camera is focused and screen brightness on the desktop is sufficient. You can also try manual pairing using the provided connection link.
Connection failed or Transfer is slow
Slow transfers are usually caused by weak Wi-Fi signals or older 2.4GHz routers. Move closer to your router or switch to a 5GHz network or wired LAN for optimal speeds.
Mobile download not starting or Files not appearing
Check your mobile browser's download manager. On iOS Safari, check the "Downloads" folder in the Files app. On Android, check the system Downloads folder.

Frequently Asked Questions

What is BeeDrop?
BeeDrop is a local file sharing tool that allows you to securely send files between nearby computers and mobile devices without using cloud servers.
Is BeeDrop free?
Yes, BeeDrop is completely free for direct local network transfers.
Does BeeDrop require the internet?
No. BeeDrop transfers files directly over your local network (Wi-Fi or Mobile Hotspot). An active internet connection is only needed to download the initial installer.
Can I transfer files between Windows and Mac?
Absolutely. BeeDrop is designed for cross-platform support, enabling seamless high-speed transfers between Windows and macOS devices on the same network.
Can I use BeeDrop on Android and iPhone?
Yes. You can access the BeeDrop mobile web interface from any smartphone browser (Android or iPhone) as long as it's connected to the same network as the desktop app.
Does BeeDrop store my files?
No. Your files are transferred directly between your devices peer-to-peer and are never stored on external or cloud servers.
How does BeeDrop connect devices?
BeeDrop uses a discovery protocol on your local network (Wi-Fi/LAN) to find active devices. You can also connect manually via IP or by scanning a QR code.
Why can't I connect to another device?
This typically happens if devices are on different networks, or if a router's AP Isolation feature blocks device-to-device communication. Check our Troubleshooting section for help.
Where are received files saved?
On desktop, files are saved to your system's default Downloads folder. On mobile, they are saved wherever your mobile browser stores downloaded files.
What platforms does BeeDrop support?
We currently provide official desktop installers for Windows (10/11) and macOS (Intel & Apple Silicon), alongside web-based access for Android and iOS mobile devices.
